## Problema Attuale: Layout Video.js

**Stato:** NON RISOLTO

**Situazione:**
- Il video appare SOTTO il box grigio `player-container`
- `overflow: hidden` nasconde il video
- `position: absolute` non funziona con Video.js
- `fluid: true` di Video.js ignora il container padre

**Cosa ho provato:**
1. `position: absolute` + `width/height 100%` → video va fuori
2. `padding-bottom: 56.25%` (trucco aspect-ratio) → non funziona
3. `fluid: false` + `aspect-ratio: 16/9` → controlli vanno fuori
4. `fluid: true` + `overflow: hidden` → video nascosto

**Causa:** Video.js con `fluid: true` crea il suo container che non rispetta il padre CSS.

**Da investigare:** Come contenere Video.js dentro un box CSS personalizzato.
