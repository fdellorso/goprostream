## Note per rollback

Se le nuove versioni causano problemi:

```bash
# Torna a Video.js 7.x
cp player/js/video.min.js.bak7 player/js/video.min.js
cp player/css/video-js.min.css.bak7 player/css/video-js.min.css

# Torna a hls.js 1.5.7
cp player/js/hls.min.js.bak157 player/js/hls.min.js
```
