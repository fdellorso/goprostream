# Handoff HLS.js - 23 Agosto 2026

## Problema

`hlsjs.html` restituiva **404 Not Found** nonostante il file esistesse nel container.

## Sintomi

```
dashboard.html → ✅ 200 OK
videojs.html   → ✅ 200 OK
hlsjs.html     → ❌ 404 Not Found
```

## Verifiche

- ✅ File esiste in `/mnt/player/hlsjs.html`
- ✅ File leggibile (`cat` funziona)
- ✅ Permessi corretti (`-rw-r--r--`)
- ✅ Bind mount configurato
- ✅ Nginx serve correttamente altri file

## Causa

Bug sconosciuto nginx/podman. Rinominare il file risolve il problema.

## Soluzione

Rinominare `hlsjs.html` → `streamhls.html`

## Modifiche effettuate

| File | Modifica |
|------|----------|
| `player/hlsjs.html` | Rinominato in `streamhls.html` |
| `player/hlsjs.html.bak` | Backup del file originale |
| `player/streamhls.html` | Nuovo file con header/footer armonizzati |
| `player/dashboard.html` | Link aggiornato a `streamhls.html` |
| `player/videojs.html` | Link aggiornato a `streamhls.html` |

## streamhls.html - Caratteristiche

- ✅ Header armonizzata (come videojs.html)
- ✅ Nav-links (Dashboard, Video.js, HLS.js)
- ✅ Status-bar con check stream
- ✅ Bottone "Restart Stream"
- ✅ Footer/status-bar
- ✅ HLS.js 1.5.7 (locale, funziona offline)
