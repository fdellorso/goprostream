# Handoff — 2026-08-29 11:45

## Sessione: Auto-Recovery GoPro dopo Cambio Batteria

### Obiettivo
Implementare un sistema di auto-recovery che gestisce automaticamente il cambio batteria della GoPro senza intervento manuale.

### Problema
Dopo un cambio batteria, la GoPro si riavvia ma non riprende lo streaming UDP automaticamente. Il supervisore riavviava FFmpeg ma non mandava il comando per riavviare lo streaming, lasciando il sistema bloccato.

---

## Modifiche Implementate

### 1. Nuovo Stato: WAITING_FOR_GOPRO
**File:** `python/goprostream.py`

Il supervisore può entrare in stato `WAITING_FOR_GOPRO` quando la GoPro non è raggiungibile. In questo stato:
- Controlla la GoPro ogni 10 secondi
- Max 30 tentativi (5 minuti)
- Se supera il timeout, invia warning alla dashboard

```python
def _check_gopro_online() -> bool:
    """Verifica se la GoPro è raggiungibile via HTTP."""
    
def _check_gopro_streaming_status() -> bool:
    """Verifica se status.17=1 (multistream attivo)."""
    
def _send_dashboard_warning(message: str) -> None:
    """Scrive warning JSON per la dashboard."""
    
def _clear_dashboard_warning() -> None:
    """Rimuove il warning dalla dashboard."""
```

### 3. Contatore NOSOCKET
**File:** `python/goprostream.py`

Aggiunto contatore `nosocket_count` nel supervisore:
- Se FFmpeg è vivo ma socket=NOSOCKET per 30 secondi
- Invia restart streaming alla GoPro
- Reset quando socket torna ESTABLISHED

### 4. Restart con goprocam
**File:** `python/goprostream.py`

```python
def _restart_stream_gopro(self) -> None:
    """Riavvia lo streaming UDP sulla GoPro usando goprocam."""
    try:
        self._gopro.livestream("start")  # ← NUOVO: usa goprocam
    except Exception:
        # Fallback: HTTP restart
        url = f"http://{GOPRO_IP}/gp/gpControl/execute?p1=gpStream&a1=proto_v2&c1=restart"
```

**Scoperta chiave:** Il comando HTTP `/execute?p1=gpStream&a1=proto_v2&c1=restart` NON funziona dopo un cambio batteria. Solo `goprocam.livestream("start")` riesce a riavviare lo streaming UDP.

## Flusso Completo Auto-Recovery

```
Cambio batteria → GoPro si riavvia
    ↓
Socket TRANSIENT rilevato (10s)
    ↓
Socket TRANSIENT per 30s → Kill FFmpeg
    ↓
Check GoPro online?
    ↓ NO → Stato WAITING_FOR_GOPRO (max 5 min)
    ↓ SI
Riavvio FFmpeg (si mette in ascolto UDP:8554)
    ↓
Socket NOSOCKET per 30s?
    ↓ SI → goprocam.livestream("start")
    ↓
GoPro riprende streaming UDP
    ↓
FFmpeg riceve dati → converte RTMP
    ↓
Nginx genera HLS → HTTP 200
    ↓
✅ RECOVERY COMPLETO
```
