## Conoscenza acquisita

### Video.js

- `aspectRatio: "16:9"` nel data-setup **forza** `fluid(true)`
- `fluid(true)` aggiunge padding-top: 56.25%
- `.vjs-tech` (elemento video) non eredita dimensioni dal parent
- Video.js inietta CSS automaticamente (non rimovibile)
- Struttura interna: player → poster → controls → tech

### GoPro Streaming

- La GoPro non manda UDP finché non riceve comando restart
- Lo stream si ferma dopo un po' (causa da investigare)
- KeepAlive della libreria goprocam ha while True infinito
- Servono 2 processi: Python (keepalive) + FFmpeg (conversione)
