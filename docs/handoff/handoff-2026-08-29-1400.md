## Note per il Prossimo

- Il container nginx-rtmp usa `network_mode: host` (necessario per proxy API a GoPro)
- I certificati SSL vengono rinnovati automaticamente via cron
- Dopo ogni rinnovo certificato, nginx viene riavviato automaticamente
- La dashboard mostra warning se la GoPro è offline per >5 minuti
