# Handoff — 2026-08-24

## Sessione: Migrazione frontend a Alpine.js

### Obiettivo
Migrare il frontend vanilla JS (dashboard, streamhls, videojs) ad Alpine.js per rendere il codice dichiarativo, reattivo e manutenibile.

### Cosa è stato fatto

#### 1. Pulizia file obsoleti
- Cancellati: `hlsjs.html.bak`, `videojs.html.bak`, `video-js.min.css.bak7`, `hls.min.js.bak157`, `video.min.js.bak7`
- Archiviati: `debug-videojs.html` → `player/archive/`

#### 2. Migrazione streamhls.html
- Alpine.js via file locale (`/js/alpine.min.js`)
- Componente `player()` con stato reattivo: `streamActive`, `statusText`, restart state
- HLS.js inizializzato via `x-ref`, polling con `fetch` + `async/await`
- `x-cloak` per evitare flash di contenuti

#### 3. Migrazione videojs.html
- Stessa struttura di streamhls (componente `player()`)
- Video.js si auto-inizializza via `data-setup`
- Status bar e restart identici a streamhls

#### 4. Migrazione dashboard.html (il grosso del lavoro)
- Componente `dashboard()` con stato centralizzato
- **Tabs**: `x-show` + `@click` invece di manipolazione DOM
- **Status dots**: `:class` reattivo (hls, rtmp, gopro)
- **100+ campi status**: `x-text` con `mapVal()` — niente più `getElementById`/`setText`
- **Log**: array reattivo con `x-for`
- **Comandi GoPro**: `@click` + `async/await` — niente più `XMLHttpRequest`
- **Highlights bottoni**: `isActive()` + `:class` su tutti i `data-group`
- **Avanzato toggle**: `showAdvanced` reattivo
- **Input fields**: `x-model` (wifiSsid, wifiPass, delPath, streamBitrate, rawCmd)
- **Risultato comando**: display reattivo vicino all'input raw

#### 5. Migrazione tutta a file locali
- Alpine.js scaricato da CDN → `/js/alpine.min.js` (54KB)
- Zero dipendenze esterne, frontend funziona offline

#### 6. Miglioramenti UX
- `mapVal()` ritorna `'N/A'` per `undefined`/`null`
- Fallback manuali da `'...'` → `'N/A'` (10 campi)
- Campi contatori da `'0'` → `'N/A'` quando GoPro è spenta
- `x-cloak` su tutti i file per evitare flash al caricamento
